# 公司小助手

铁路单位内部用的三个小工具，这一版先把界面和操作流程做出来。数据存在浏览器本地，刷新还在，不是正式账号系统。

## 启动

```bash
cd company-assistant
npm install
npm run dev
```

浏览器打开终端里给出的地址。

## 三个模块

1. **工会助手**。工会管理自己写单选或多选问卷，题目和选项可以配图，推送给全体工会成员。小组长只看本组谁填了、谁没填。都填完后生成签收单，可下载 Excel 或打印。表头是临时的，等正式样表再换。
2. **考勤统计**。放入两张 Excel：内网导出（请假、出差、市内公出等）和另一张要合并的表。页面会读出表头和前几行。日历先按演示规则展示，等样表确定列的对应关系后再做真正合并。人力管理员可查看并修改全体，部门负责人看本部门，其他人只看自己。
3. **发票助手**。拖入未签章 XML，预留下载已签名文件和电子税务局账号密码的位置。不会连接税务局，也不会保存密码。

用户管理里可以新增人员、改身份、重置回 `888888`。登录页有「恢复演示数据」。
